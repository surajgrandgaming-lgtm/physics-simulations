# Math Challenges

One folder per math topic that needs a bespoke 3D scene.
Most math topics should use `src/three/kit/math/` components (ParametricCurve,
SurfacePlot, UnitCircle) composed directly in the challenge page.
Only create a folder here for topics needing unique geometry or interaction
that the kit components cannot handle via props alone.

Folder naming: matches the topic slug in `src/content/math/<module>/<topic>/`
